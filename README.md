# 🌟 Launching Leaders Facilitator Network

A web-based platform for joining WhatsApp groups associated with the **Launching Leaders Facilitator Network**. This project allows users to select their stake and facilitator, view custom details, and join the corresponding WhatsApp group seamlessly.

---

## 📌 Features
✅ **Stake and Facilitator Selection**: Users can select their stake and facilitator from a dropdown menu.
✅ **Custom Messages**: Displays custom information for specific facilitators (e.g., venue, course start date).
✅ **WhatsApp Integration**: Redirects users to the correct WhatsApp group based on their selection.
✅ **Admin Notifications**: Sends user details to the admin via WhatsApp if an additional message is provided.
✅ **Responsive Design**: Works on both desktop and mobile devices.

---

## 🛠️ How to Use
### For Users
1. Open the deployed site (e.g., on Netlify or GitHub Pages).
2. Fill in your **Full Name**, **Email**, and **Phone Number**.
3. Select your **Stake** and **Facilitator** from the dropdown menus.
4. (Optional) Add an **Additional Message** if you want to notify the admin.
5. Click **"Join WhatsApp Group"** to be redirected to the corresponding WhatsApp group.

---

## 🚀 Deployment
### Using Netlify
1. **Fork this repository** or download the HTML file.
2. **Drag and drop** the `index.html` file into the [Netlify Drop](https://app.netlify.com/drop) zone.
3. **Deploy**: Netlify will automatically deploy your site and provide a live URL.

### Using GitHub Pages
1. **Fork this repository**.
2. Go to **Settings > Pages** in your GitHub repository.
3. Select the `main` branch and the `/root` folder.
4. Click **Save**, and GitHub will deploy your site.
